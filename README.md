# show-builder

Tools for building and previewing LED light shows for The Gothic Folly — a
full-scale LED cathedral debuting at Burning Man 2026.

## What's here

```
show-builder/
  getting-started.md   ← full walkthrough for sequence designers (xLights or TouchDesigner)
  CLI-PLAYBACK.md       ← headless render + live preview from the shell, no xLights GUI
  cathedral-3d-sim.html ← 3D browser simulator (all zones)
  rose-window-sim.html  ← 2D rose window simulator
  arches-sim.html       ← 2D arches simulator
  pixel-map/            ← LED position data (used by the simulators)
  relay/                ← local relay server + CLI playback tooling
  xlights/              ← xLights project: models, layout, sequences
  td/                   ← TouchDesigner patch generator and pixel data
```

## Getting started

If you're building a sequence, start with **[getting-started.md](getting-started.md)** —
it covers installing xLights or TouchDesigner, opening the project, and
previewing your show live in the browser simulator.

If you want to render and preview a sequence from the command line without
opening the xLights GUI, see **[CLI-PLAYBACK.md](CLI-PLAYBACK.md)**.
